ESXi Root Password Accepted from Remote Host

Last updated 4 days ago on 2026-09-30
Created 4 days ago on 2026-09-30

About

Detects hostd accepting the ESXi root password from a remote address. A successful remote root login opens the Host Client or the API with full control of the host. Local sessions from 127.0.0.1 are left out of the rule.

False Positives
Administrators sign in to the Host Client or the API as root from a jump host during maintenance. Confirm the source address is a known workstation and that the session does not continue into SSH enablement, file copies to `/tmp`, or virtual machine shutdowns.
