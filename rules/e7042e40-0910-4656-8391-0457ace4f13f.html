Entra ID FIDO2 Passkey Credential Registered

Last updated 5 days ago on 2026-11-18
Created a month ago on 2026-10-21

About

Identifies the registration of a FIDO2 or passkey authentication method for a Microsoft Entra ID user or admin. Passkey enrollment is usually legitimate onboarding, but an adversary who has taken over an account can register their own passkey for durable, phishing-resistant persistence that survives password resets and session revocation. This is a building block rule that captures the registration population for correlation and baselining rather than standalone alerting.

False Positives
Legitimate FIDO2 and passkey onboarding commonly generates this event, especially for new users or during a passwordless rollout. This rule is informational only and is intended for correlation and baselining, not standalone alerting. When triaging a correlated signal, investigate registrations where the initiator differs from the target user, the registered authenticator's AAGUID is unknown to the organization, attestation is absent, or the registration was preceded by an anomalous sign-in.
