Suspicious IDE Extension Installation from VSIX

Last updated 6 days ago on 2026-10-26
Created 6 days ago on 2026-10-26

About

Detects installation of an IDE extension from a local VSIX ("--install-extension" with a ".vsix" path) when that path is in a staging directory, or the parent is a script host or installer. VS Code and compatible editors (Cursor, VSCodium, Windsurf) use this CLI to sideload extensions outside the marketplace.

✄𐘗FROM logs-endpoint.events.process-* METADATA _id, _version, _index
| WHERE MV_CONTAINS(event.category, "process")
  AND MV_CONTAINS(event.type, "start")
  AND TO_LOWER(process.command_line) LIKE "*--install-extension*"
  AND TO_LOWER(process.command_line) LIKE "*.vsix*"
  AND (
    (
      host.os.type == "windows"
      AND (
        TO_LOWER(process.command_line) RLIKE
          """.*\\users\\public\\.*|.*\\appdata\\local\\temp\\.*|.*/users/public/.*|.*/appdata/local/temp/.*"""
        OR TO_LOWER(process.parent.name) IN (
          "mshta.exe",
          "wscript.exe",
          "cscript.exe",
          "powershell.exe",
          "msiexec.exe",
          "pwsh.exe",
          "node.exe",
          "bun.exe",
          "py.exe"
        )
        OR TO_LOWER(process.parent.name) LIKE "python*"
      )
    )
    OR
    (
      host.os.type IN ("macos", "linux")
      AND (
        TO_LOWER(process.command_line) LIKE (
          "*/tmp/*",
          "*/var/tmp/*",
          "*/private/tmp/*",
          "*/dev/shm/*",
          "*/users/shared/*"
        )
        OR TO_LOWER(process.parent.name) IN (
          "osascript", "node", "bun"
        )
        OR TO_LOWER(process.parent.name) LIKE "python*"
      )
    )
  )
| KEEP
    _id,
    _version,
    _index,
	data_stream.namespace,
    @timestamp,
    host.name,
	host.id,
	agent.id,
    host.os.type,
    user.name,
	user.domain,
    process.name,
    process.parent.name,
    process.command_line,
    process.parent.command_line
