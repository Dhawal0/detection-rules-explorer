Potential Prompt Injection Coercing Shell Execution

Last updated 9 days ago on 2026-10-09
Created 9 days ago on 2026-10-09

About

Detects shells or scripting interpreters launched from a parent command line that contains common LLM prompt-injection or jailbreak language. Attackers (or malicious content ingested by an agent) use instruction-override, DAN/developer- mode, system-prompt extraction, and safety-filter bypass phrasing to coerce GenAI coding agents and automation wrappers into running attacker-chosen commands. When that injected text reaches a child shell or interpreter, it is a strong signal that untrusted prompt content is crossing into local code execution, enabling credential theft, data exfiltration, persistence, or further tool abuse under the user's privileges.

False Positives
Approved red-team, evaluation, or detection-engineering tests that deliberately include jailbreak strings (such as DAN or "ignore previous instructions") in prompts or regex experiments run through GenAI agent shells. Exclude known lab hosts or lower severity after validation. ; Documentation that mentions "developer mode", "jailbreak", or "without restrictions" in a non-adversarial context.
