Potential Uninstall Entry Concealment

Last updated a month ago on 2026-09-17
Created a month ago on 2026-09-17

About

Identifies execution of the Hide From Uninstall List utility or a registry change that marks an installed application as a system component, causing Windows to omit it from Programs and Features. Adversaries may use either method to conceal remote-access, security, or other software.

False Positives
Application installers, software-management systems, and administrators may legitimately set SystemComponent during deployment, updates, packaging, or shared-device and kiosk hardening. Confirm the matched branch, binary or uninstall target, initiating identity, host, parent process, and change window against the change record before adding a narrow exception.

text code block:
✄𐘗any where host.os.type == "windows" and
(
  (
    event.category == "process" and event.type == "start" and
    (process.name : ("HideUL.exe", "HideUL_x64.exe") or ?process.pe.original_file_name : "HideUL.exe")
  ) or
  (
    event.category == "registry" and event.type == "change" and
    registry.value : "SystemComponent" and
    registry.path : (
      "*\\Software\\Microsoft\\Windows\\CurrentVersion\\Uninstall\\*",
      "*\\Software\\WOW6432Node\\Microsoft\\Windows\\CurrentVersion\\Uninstall\\*"
    ) and
    registry.data.strings : ("1", "0x00000001") and
    not registry.path : "*Microsoft EdgeWebView\\SystemComponent" and
    not (
      registry.path : "*\\{*}\\SystemComponent" and
      process.executable : ("?:\\Windows\\System32\\msiexec.exe") and
      user.id : "S-1-5-18"
    )
  )
)
